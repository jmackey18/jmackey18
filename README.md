### Agentic AI for Social Science

A collaborative capstone project that provides social science researchers with
a no-code environment for exploring, cleaning, and analyzing structured data.

My contributions have focused on the **DeepAnalyze** component, an interactive
AI analysis system that combines LLM reasoning with Python code execution.

Some of my work includes:

- Modularized the DeepAnalyze backend into separate API, model communication,
  analysis, execution, session-storage, and workspace components
- Added validated CSV and TXT ingestion with file-size limits, metadata
  extraction, checksums, column detection, and record counting
- Preserved dataset metadata through workspace operations and session
  import/export workflows
- Supplied dataset descriptions to the AI analysis coordinator for
  file-aware analysis
- Added backend tests and verified ingestion and analysis using a
  10,000-row dataset
- Documented the backend architecture and created a live demonstration guide

**Technologies:** Python, FastAPI, Next.js, Docker, MongoDB, PostgreSQL,
Prometheus, Grafana, Nginx, and OpenAI-compatible APIs

### OU Park

A team-built application designed to make finding parking on the University of
Oklahoma campus easier.

The application helps users:

- View simulated parking-lot occupancy and availability
- Choose a parking location through an interactive map
- Save the location of their vehicle
- Receive walking directions back to their saved parking spot
- Get parking recommendations based on location and preferences

I contributed to the application's development as part of a collaborative
software-engineering team, working with mapping, parking information, and
user-facing functionality.

**Technologies:** JavaScript, Node.js, Express.js, React Native, Firebase,
SQL, and Google Maps APIs
